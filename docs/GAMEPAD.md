## 1. 目标与范围

新增「手柄模式」：猫正对用户，抱着手柄在胸前使用，用户按手柄时，对应按键高亮并飘出浮动键位。

- 手柄款式两种：Xbox、PS5，只在布局和图标上区分，配色统一为 Classic 鼠标的暖白加橙色。
- 模式三种：自动、始终键盘、始终手柄。自动模式下检测到手柄操作就切到手柄，手柄闲置并有键鼠操作时切回键盘。
- 输入来源：先做 XInput（覆盖 Xbox 手柄以及经 Steam Input 或 DS4Windows 映射的手柄）；DualSense 原生 HID 放到后期，不在本期。
- 不做：手指、按键与手指的精确对位、震动、陀螺仪。

## 2. 文件级改动清单

- 新增 `GamepadArt.cs`：静态类，仿照 `MouseArt` 和 `DeskArt`，提供 `Draw(dc, style, state)`，只负责画手柄。
- 新增 `GamepadInput.cs`：XInput 轮询，把状态变化翻译成事件，调用 `CatScene`。
- `CatScene.cs`：增加手柄模式的状态（按键强度表、摇杆偏移、扳机量），模式为手柄时调用 `GamepadArt.Draw` 代替 `DrawDesk`，并按第 5 节驱动猫的姿态。
- `CatArt.cs`：手臂画法增加「抬爪程度」覆盖参数，手柄姿态用，见第 5 节。
- `DeskStyle.cs`：增加 `GamepadStyle { Xbox, PS5 }` 与 `GamepadMode { Auto, Keyboard, Gamepad }` 两个枚举。
- `Preferences.cs`：增加 `Gamepad`（默认 Xbox）与 `Mode`（默认 Auto），读写沿用现有 `ReadStyle` 和 XML 属性的写法，属性名取 `gamepad` 与 `gamepadMode`。
- `StyleMenu.cs`：仿照 `Keyboards()` 和 `Mice()` 增加 `Gamepads()`，菜单项带款式预览缩略图。
- `App.cs`（托盘菜单）：增加「手柄模式」单选子菜单（自动、键盘、手柄）和「手柄款式」组。
- 不改 `WindowsInput.cs` 的键鼠逻辑；自动模式需要的「最近一次键鼠操作时间」从现有的 `Strike` 和 `MouseButton` 调用处记录。

## 3. GamepadArt.cs 画法规范

### 3.1 坐标与投影

手柄先在「平面坐标」里定义，再投影到 480×320 的场景。平面坐标里 +x 对应屏幕向左，+y 对应屏幕向上（手柄朝向猫，等于旋转了 180°）。

- 手柄中心 (214, 192)，宽度 80，所以缩放 `S = 80 / 94 = 0.8511`。
- 压扁系数 `Ky = 0.80`，透视强度 `Persp = 0.12`。
- 深度系数 `t(y) = clamp((-y + 34) / 63, 0, 1)`，`sc(y) = (1 / (1 - Persp * t)) / (1 / (1 - Persp * 0.5))`。
- 屏幕坐标：`X = 214 - x * S * sc(y)`，`Y = 192 - y * S * Ky * sc(y)`。
- 圆在屏幕上是椭圆：`rx = r * S * sc`，`ry = r * S * Ky * sc`。
- 贝塞尔曲线直接投影控制点（和 `DeskArt` 的做法一致）。
- `sc` 的参考值：y=-30 时 1.068，y=0 时 1.005，y=34 时 0.940。

机身轮廓（平面坐标）：

`M -30,-22 C -22,-26 22,-26 30,-22 C 40,-20 46,-6 46,8 C 47,22 44,34 36,34 C 28,34 24,26 18,19 L -18,19 C -24,26 -28,34 -36,34 C -44,34 -47,22 -46,8 C -46,-6 -40,-20 -30,-22 Z`

### 3.2 图层顺序（自下而上）

1. 扳机（左右各一，画在机身壁之前，壁会盖住它的根部）。
2. 机身壁：偏移 3.6、2.6、1.6、0.6 四层叠画，颜色取 `625E55` 到 `A8A393` 的线性混合，系数为 `1 - 偏移/3.6`。
3. 机身底边描线：偏移 3.6，笔 `504C45`，宽 0.85，圆角连接，不填充。
4. 机身顶面：Crown 径向渐变，笔 `504C45`，宽 0.55。
5. 高光线：平面路径 `M 41,12 Q 43,23 37,31`，白色，宽 0.95，圆头。
6. 肩键（左右各一）。
7. PS5 触控板（Xbox 没有）。
8. 摇杆、十字键、Xbox 的视图与菜单小点。
9. 面键（绘制顺序：下、左、右、上）。

### 3.3 颜色与渐变

- Crown（顶面）：中心 (.37, .27)，原点 (.36, .24)，半径取鼠标同款，色标 `FFFEF5`、`F3F1E4`（位置 .64）、`C4C1B3`。
- 键帽 Ramp（空闲）：起点 (.3, 0)，终点 (.7, 1)，`FBF9EF` 到 `E2DECC`。
- 键帽 Ramp（按下）：同样的方向，`FFED8F` 到 `FFAE37`。
- 前沿亮边：`FFF4AE`，宽 1.06，圆头。
- 键帽底座（socket）：`989383`。
- 橡胶 Ramp（摇杆帽）：`FFDE77` 到 `CB8C28`；摇杆凹槽 `776440`，笔 `504C45`，宽 0.45；防滑纹 `CB8C28`，宽 0.48。
- 深色 Ramp（扳机）：`68727C` 到 `414A52`；触控板 Ramp：`414950` 到 `1B2228`，笔 `191D23`，宽 0.4。

### 3.4 部件参数

**扳机**（平面路径，右侧；左侧把 x 取反）：`M tx0,-23 C tx0+2,bulge tx1-2,bulge tx1,-21.5 L tx1,-19 L tx0,-20 Z`。

- Xbox：tx0=19，tx1=34，bulge=-37；PS5：tx0=17，tx1=35，bulge=-39。
- 屏幕上整体下移 2.0，按下时再下移 `1.6 * 强度`；填充深色 Ramp；笔 `8B95A0`，宽 0.55，按下时按强度混向 `FFD25A` 并加粗到 0.9。

**肩键**（平面路径，右侧；左侧 x 取反）：`M bx0,-23.6 C bx0+6,-24.2 bx1-5,-23.4 bx1,-19.3 L bx1-1.6,-15.8 C bx1-6,-19.4 bx0+6,-20.0 bx0,-19.6 Z`。

- Xbox：bx0=16，bx1=33；PS5：bx0=18，bx1=31（更短）。
- 躺在机身顶面近缘，整体在机身轮廓内，不得探出。
- 底座层：填 `A8A393`，笔 `504C45` 宽 0.5，偏移 +1.3，按下时不透明度降到 `1 - 0.6 * 强度`；键帽层：空闲 Ramp，偏移 `0.2 + 1.1 * 强度`；强度大于 0 时叠一层按下 Ramp，不透明度等于强度。

**摇杆**：半径 7.2。

- 位置：Xbox 左 (-27, -4)、右 (15, 9)；PS5 左 (-14, 9)、右 (14, 9)。
- 凹槽椭圆在原位；帽的中心 = 凹槽中心上移 0.9 再加偏转量。
- 帽的半径是凹槽的 0.84；3 条防滑纹，纵向位置分别为 -0.28、0.05、0.38 倍 ry，半宽 0.42 倍 rx。
- 偏转：平面偏移最大 1.9（左）与 1.6（右），投影后的屏幕位移乘 1.6 作用在帽上。
- 摇杆按下（L3、R3）：帽再下沉 0.9。

**十字键**：位置 Xbox (-15, 9)，PS5 (-27, -4)。

- 多边形顶点（平面）：(-2.3,-5.8)、(2.3,-5.8)、(2.3,-2.3)、(5.8,-2.3)、(5.8,2.3)、(2.3,2.3)、(2.3,5.8)、(-2.3,5.8)、(-2.3,2.3)、(-5.8,2.3)、(-5.8,-2.3)、(-2.3,-2.3)。
- 先画底座层（`989383`，笔宽 0.65，圆角连接），再画上移 0.6 的键帽层（空闲 Ramp，笔 `989383` 宽 0.3）。
- 按下方向时整个十字下沉 0.8，被按的那一臂叠按下 Ramp。

**Xbox 视图与菜单键**：平面位置 (±6, -1)，半径 1.6，填 `989383`；按下时变 `FFAE37`。

**PS5 触控板**：圆角矩形 (-14,-19) 到 (14,-8)，圆角 3，只有这一块，不画周围的大面板。

**面键**：中心 (27, -4)，间距 7.4，按键半径 3.4。

- 平面位置：上 (27, -11.4)、下 (27, 3.4)、左 (19.6, -4)、右 (34.4, -4)。
- 画法沿用 `MouseArt` 的按键：底座椭圆半径加 0.35；键帽偏移 `-0.4 + 1.5 * 强度`；叠按下 Ramp，不透明度等于强度；强度大于 0 时加一道底座色肩线（宽 0.64）和前沿亮边。

### 3.5 图标与款式差异

图标跟着手柄旋转 180°，朝向猫；浮动键帽上的字仍然是正的，方便阅读。

- Xbox：上 Y、右 B、左 X、下 A，加粗无衬线字母，字号 `rx * 1.34`，基线在中心下移 `ry * 0.52`；颜色分别为 A `2F9E4B`、B `D6453D`、X `3B7FD4`、Y `D99A0B`。
- PS5：上 △、右 ○、左 □、下 ✕，用笔画绘制，宽 0.78，圆头圆角；颜色分别为 △ `33B38E`、○ `E05A63`、□ `D98BB9`、✕ `4F86E0`。
- 按下的键，图标颜色向 `4A2A00` 混合 50%，保证在黄色键帽上看得清。
- 因为手柄旋转了 180°，屏幕上看 Xbox 的 A 在菱形上方、Y 在下方，这是预期效果。
- 款式差异总结：Xbox 的肩键更长、扳机略窄、摇杆左上右下不对称、有视图和菜单小点；PS5 的摇杆左右对称、方向键在左侧、有触控板、肩键更短、扳机略宽。

## 4. CatScene 集成

- 手柄模式下不画键盘和鼠标，改画手柄；绘制顺序为尾巴、身体、手柄、双臂、头、浮动键帽（手臂在手柄之后画）。
- `lean` 固定为 0。
- 视线：沿用现有 gaze 逻辑，目标点改成最近被按键的屏幕坐标；`gy` 目标固定 0.9（低头看手柄），`gx` 目标取 `tanh((键位屏幕 x - 214) / 130)`。
- 呼吸、尾巴摆动、眨眼全部沿用现有逻辑，不改。
- 按键强度：按下时 0.05 秒内升到 1，按住期间保持 1，松开后用 0.33 秒按 `1 - Smooth(t / 0.33)` 衰减。扳机是模拟量，强度直接取 0 到 1 的扳机值。

## 5. 猫的姿态与爪子

- 爪子基准位置（屏幕）：画面左侧的爪 (190.68, 175.49)，右侧的爪 (237.32, 175.49)，即握把根部的平面点 (±30, 27) 投影后再各向外偏 1、向下偏 1。
- 分工：画面左侧的爪负责面键、右摇杆、右肩键、右扳机；右侧的爪负责左摇杆、十字键、左肩键、左扳机。
- 点按反应：爪子朝被按键方向偏移 `(键位屏幕坐标 - 爪基准) * 0.24 * Beat(age)`，同时向下压 `1.4 * Beat(age)` 像素。`Beat` 沿用 `CatScene`：前 0.065 秒为 1，之后按 `1 - Smooth((age - 0.065) / 0.175)` 衰减，0.24 秒归零。
- 拨摇杆：对应的爪子活跃度取 `0.75 * 摇杆包络`，并跟着摇杆帽的屏幕位移移动，幅度乘 1.2；左摇杆由画面右侧的爪负责，右摇杆由画面左侧的爪负责。
- 不画手指，爪子保持原项目的连指手套形状。
- 手臂抬爪程度：已定为方案 B，固定 0.25，并省略爪下的浅灰弧线（对比见 `gamepad-paw-compare.png`）。

## 6. 浮动键位

完全沿用 `CatScene` 现有的键帽飘动逻辑，只替换文字和起点：

- 起点 = 被按键的屏幕中心加 (随机 -5 到 5, -14)，角度随机 ±7°。
- 飞行：`travel = 1 - (1 - p)^2`，`p = age / 0.89`；中心 = 起点 + (角度 \* travel, -53 \* travel)。
- 非最新的键帽：不透明度 `1 - Smooth((p - 0.55) / 0.45)`，0.89 秒后移除。
- 最新的键帽：0.6 秒后在 0.42 秒内平滑飘到尾巴处 (298, 214) 并停留，沿用原来的存活时间。
- 被按键的屏幕中心（用于起点，平面点投影得到）：Xbox 与 PS5 的面键相同，上 (190.4, 200.0)、右 (184.3, 194.8)、左 (197.1, 194.8)、下 (191.1, 189.7)；肩键右 (192.2, 205.9)、左 (235.8, 205.9)；扳机右约 (190.0, 211.6)、左约 (238.0, 211.6)。
- 文字：
  - Xbox：A、B、X、Y、LB、RB、LT、RT、LS、RS、View、Menu，方向键用 ↑ ↓ ← →。
  - PS5：✕、○、□、△、L1、R1、L2、R2、L3、R3、Create、Options，方向键同上。
  - 超过 3 个字符的用 10.5 号字，其余沿用 13.5 号半粗。
- 手柄模式下 `Labels` 偏好为关闭时，不画键帽，行为与键盘模式一致。

## 7. 输入层（GamepadInput.cs）

- 用 P/Invoke 调 `xinput1_4.dll` 的 `XInputGetState`，找不到时依次回退 `xinput1_3.dll`、`xinput9_1_0.dll`；全部失败则静默禁用手柄功能，不得影响键鼠模式。
- 状态结构：`PacketNumber`，以及按键位掩码、左右扳机（0 到 255）、左右摇杆各两个轴（-32768 到 32767）。`PacketNumber` 不变时直接跳过。
- 按键位掩码：上 0x1、下 0x2、左 0x4、右 0x8、Start 0x10、Back 0x20、L3 0x40、R3 0x80、LB 0x100、RB 0x200、A 0x1000、B 0x2000、X 0x4000、Y 0x8000。
- 阈值：扳机 30；左摇杆死区 7849；右摇杆死区 8689。
- **轮询节奏：有手柄连接时 60Hz；没连手柄的槽位每秒只探测一次。** 对空槽调用 `XInputGetState` 很慢，禁止每帧轮询 4 个槽位。
- 在 UI 线程之外轮询时，用和现有代码一致的方式把事件送回 UI 线程，再调用 `CatScene`。
- 款式映射：PS5 款式下，XInput 的 A、B、X、Y 依次对应 ✕、○、□、△，LB、RB、LT、RT 依次对应 L1、R1、L2、R2，Back 和 Start 对应 Create 和 Options。XInput 无法区分手柄品牌，款式由偏好决定，不自动识别。

## 8. 模式切换、偏好、托盘

- 偏好新增 `Gamepad`（Xbox 或 PS5）和 `Mode`（自动、键盘、手柄），读写失败时回退默认值。
- 托盘「手柄模式」子菜单是三项单选；「手柄款式」带预览缩略图，缩略图复用 `GamepadArt.Draw` 画出的静态手柄。
- 自动模式的规则：
  - 任意手柄按键、扳机超过阈值或摇杆越过死区，切到手柄。
  - 手柄闲置满 5 秒且之后出现键盘或鼠标按键，切回键盘。
  - 每次切换后至少停留 1.5 秒，防止来回闪。
  - 在手柄活跃期间，忽略键盘和鼠标事件，避免猫的姿态抖动。
- 模式为「始终手柄」时，键鼠事件一律不驱动猫；模式为「始终键盘」时，手柄事件一律不驱动猫。

## 10. 已确认的决定

1. 手臂姿态：采用方案 B（抬爪程度 0.25，不画爪下弧线）。
2. 手柄尺寸：宽 80，约为鼠标宽度的 2.7 倍；严格取鼠标的 1.5 倍会被两只爪盖住，所以不取。尺寸由常量 `Width` 控制，随时可调。
3. 最新键帽的停留时间沿用原项目的 5.8 秒；参考动图里只停 2.6 秒，是为了循环。
4. 按键强度：按住期间保持 1，松开后用 0.33 秒衰减；参考动图里是按下 0.1 秒后衰减，实现时不照搬。
5. 图标朝向猫（倒着看）已确认，浮动键帽上的字保持正向。

  - 2.90 秒：RT / R2（扳机，保持 0.3 秒）
  - 3.40 秒：LB / L1
  - 3.90 秒：LT / L2（扳机，保持 0.3 秒）
- 面键和肩键的强度：按下后 0.10 秒保持 1，再用 0.33 秒衰减（参考动图的简化做法，实现时按第 4 节改成按住保持）；扳机 0.08 秒升到 1，保持 0.3 秒，再用 0.2 秒回落。
- 摇杆：左摇杆在 4.4 到 5.4 秒画一圈，最大偏移 1.9；右摇杆在 5.1 到 6.1 秒画一圈，最大偏移 1.6；偏移量乘以 `sin(π * u)` 包络（u 为该段内的进度 0 到 1）。
- 眨眼：2.1 秒和 5.0 秒各一次，持续 0.17 秒，幅度 `sin(π * t / 0.17)`，大于 0.87 时画成闭眼的弧线。
- 眼神：缓动系数 `1 - exp(-dt * 14)`，`gy` 目标 0.9；`gx` 目标是 `tanh((最近键 x - 214) / 130)`，参考动图里额外乘了 0.9，实现时可沿用原项目不乘，差别很小。
- 键帽：飘动规则见第 6 节，参考动图里最新键帽只停 2.6 秒（为了循环），实现时用 5.8 秒。

## 12. Windows 人工验证步骤（G2 / G3）

在 Windows 上跑 `windows\build.ps1`，确认编译通过，再按下面逐项检查。任何一项不通过都停下，不要继续。

### G2 输入
1. 不插手柄启动程序：任务管理器里 CPU 占用应与平时（无手柄）基本一致——空槽每秒只探测一次，不应出现持续高占用。
2. 插上 Xbox 手柄（或经 Steam Input / DS4Windows 映射的手柄）：猫应自动切到手柄模式（默认“自动”），键盘上打字不再让猫动。
3. 依次按 A / B / X / Y：对应键变橙色高亮，同时飘出对应键帽（Xbox：A/B/X/Y；PS5 款式下显示 ✕/○/□/△）。
4. 按 LB / RB：肩键下沉变橙，飘出 LB / RB（PS5：L1 / R1）。
5. 拉 LT / RT：扳机下沉，松开后回弹；轻拉一点（不到约 1/8 行程）时扳机只动视觉，不切模式。
6. 推左摇杆画一圈：左摇杆帽跟着偏移，右爪跟着摇杆帽走；推右摇杆同理，左爪跟随。
7. 按下摇杆（L3 / R3）：摇杆帽再下沉一格。
8. 按十字键四个方向：十字键整体下沉，被按的方向变橙。
9. 按 View / Menu（或 PS5 的 Create / Options）：小圆点变橙。
10. 拔掉手柄：再按手柄无反应；键盘打字 5 秒后猫切回键盘模式。
11. 键盘模式下确认：打字、鼠标移动和点击都和原来一样，手柄不影响。

### G3 模式、偏好与托盘
1. 右键托盘 → “手柄模式”：应有 自动 / 键盘 / 手柄 三项，当前项打勾。
2. 选“手柄”：猫立刻切到手柄模式，打字和点鼠标都不再让猫动；选“键盘”：猫立刻切回键盘模式，按手柄无反应；选回“自动”恢复自动切换。
3. 右键托盘 → “手柄款式”：Xbox / PS5 两项各带手柄缩略图预览，当前项打勾；切换后手柄外观立刻变化（Xbox：左右摇杆不对称、有 View/Menu 小圆点；PS5：摇杆对称、十字键在左、有触摸板）。
4. 退出程序再重开：上次选的手柄款式和模式应保持不变（`%LocalAppData%\KeycatDesktop\preferences.xml` 里有 `gamepad` 和 `gamepadMode` 两个属性）。
5. 键盘和鼠标模式的渲染不变：打字时键盘高亮、鼠标跟随、浮动键帽都和原来一致；猫的待机、呼吸、眨眼、尾巴摆动不变。
